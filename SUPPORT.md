# Support

Use the repository's
[GitHub issue tracker](https://github.com/EdoardoBotta/RQ-VAE-Recommender/issues)
for installation problems, reproducible usage questions, and bug reports.

Before opening an issue:

1. Check the [README](README.md), [API overview](docs/api.md), and existing issues.
2. Reduce the problem to the smallest reproducible example you can.
3. Include the Python version, operating system, accelerator type, package
   version or commit, configuration file, command, and complete error message.
4. Remove credentials, personal data, and proprietary dataset content.

Support is provided on a best-effort basis by the maintainer and community; no
response-time guarantee is offered. Please use pull requests for proposed code
or documentation changes.
